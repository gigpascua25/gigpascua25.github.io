Tagging conservation grants with an LLM

A Python pipeline that reads each grant's objectives and returns three ranked biodiversity targets, each backed by a quote a reviewer can check.

Role
Team of three, working for a Philippine conservation foundation. I wrote all of the Python.
Tools
Python, pandas and the OpenAI API (gpt-4o-mini) in Google Colab.
Data
339 grants tagged by program managers and 201 untagged grants from the foundation's portfolio. None of it is published, and the foundation is not named.

The question

The foundation has to show funders how its grants line up with the 23 targets of the Philippine Biodiversity Strategy and Action Plan, 2024–2040. Program managers tag each grant by hand. We asked two things: can a model replicate the 339 human tags, and if it can, can it tag the 201 grants nobody has tagged yet?

What I did

  1. Held the framework as data: 5 themes, 23 targets and every indicator. The model returns only a target number, and the notebook looks up the name, description and theme, so an impossible pair such as Target 3 under Theme 5 cannot occur.
  2. Wrote one prompt per grant in five parts (task, context, input, constraints, output). It carries the full framework, seven worked examples of human tagging, and tie-break rules for the target pairs the framework itself blurs.
  3. Asked for three ranked targets instead of one. Grants usually touch several targets, and a single answer throws that information away.
  4. Checked every evidence quote against the grant's own text, recorded failed calls instead of dropping them, and flagged rows for review: an unverified quote, a shortlist spread across themes, or almost no objectives text.
  5. Ran the same pipeline on the tagged set to measure it, then on the untagged set.

What I found

  • The output format mattered more than the rules. Sharper rules and worked examples did not move accuracy beyond the margin of error across four runs. Changing the answer to a ranked shortlist of three did.
  • The model knows the area better than the exact target. It picks the right theme first 77.58% of the time but the exact target only 32.74%. That makes it a drafting aid: a reviewer confirms one of three suggestions instead of choosing from 23.
  • The untagged set is thin. 187 of the 201 untagged grants have no objectives text, so they are tagged from the title alone and every one is flagged for review.

Limits I flagged

  • All accuracy figures are in-sample.
  • Program managers tag by the target that receives the largest share of the budget, and the files carry one total amount with no breakdown.
  • Targets 5 and 9 share an identical indicator list in the source document, so grants between them are ambiguous in the framework itself.
  • One target is enforced at rank 1, so grants that genuinely serve several targets are flattened.
