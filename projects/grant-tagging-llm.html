LLM-assisted grant classification

A Python pipeline that uses a large language model to suggest three ranked biodiversity targets for each conservation grant, each supported by a quotation verified against the grant text.

Team
Team of three. The project partner was a Philippine conservation foundation, which is not named here.
My contribution
I wrote all of the Python code for the classification pipeline described below.
AI assistance
Following the bootcamp's approach, I used AI tools to help write the code, and reviewed and tested it myself.
Tools
Python, pandas and the OpenAI API (gpt-4o-mini) in Google Colab.
Data
339 grants tagged by the foundation's program managers and 201 untagged grants. None of this data is published.

Business question

The foundation reports to funders on how its grants align with the 23 targets of the Philippine Biodiversity Strategy and Action Plan (PBSAP) 2024–2040. Program managers currently tag each grant by hand. The team set out to answer two questions: can a language model reproduce the 339 existing human tags, and, if so, can it tag the 201 grants that have not yet been tagged?

The tool supports one team member's tagging work. Instead of reading all 23 targets for each grant, the reviewer checks three suggestions, each backed by a quotation from the grant.

How the pipeline works

  1. The PBSAP framework (5 themes, 23 targets and their indicators) is held as data. The model returns only a target number; the pipeline then looks up the target's name, description and theme, so an invalid combination such as Target 3 under Theme 5 cannot occur.
  2. Each grant is sent as one prompt in five parts: task, context, input, constraints and output format. The prompt includes the full framework, seven worked examples of human tagging, and tie-break rules for target pairs that the framework does not clearly separate.
  3. The model returns three ranked targets rather than one, because most grants relate to several targets.
  4. Each evidence quotation is checked against the grant's own text. Failed calls are recorded rather than dropped, and rows are flagged for human review when the quotation cannot be verified, the three suggestions span different themes, or the grant has little or no objectives text.
  5. The same pipeline was run first on the tagged grants to measure accuracy, then on the untagged grants.

Findings

  • Why the tool suggests three targets instead of one. The first version asked for a single target and matched the human tag for 67% of grants. Adding tie-break rules and worked examples did not improve on this: four runs scored between 62% and 68%, within run-to-run variation. The team then asked the model for a ranked shortlist of three. The correct target appeared in the shortlist for 88.79% of grants, but it was the first suggestion for only 32.74% and was more often the second (42.2%). Because the shortlist is reliable but its ordering is not, the tool presents all three suggestions and a reviewer makes the final choice.
  • The model identifies the theme more reliably than the exact target. The first suggestion matched the theme of the human tag for 77.58% of grants. The tool is therefore best used as a drafting aid that narrows 23 targets to three, not as a replacement for human tagging.
  • Misses cluster around one boundary. Of the 38 grants with no correct target among the three suggestions, 12 had been tagged Target 3 by program managers, and the model read 11 of those as Target 1. The distinction between managing a site and planning for one accounts for about a third of all misses.
  • Most untagged grants lack objectives text. 187 of the 201 untagged grants have no objectives, so they were tagged from the title alone and every one was flagged for review.

Limitations

  • All accuracy figures are in-sample.
  • Program managers tag each grant by the target that receives the largest share of its budget, but the files contain only a total amount, with no breakdown.
  • Targets 5 and 9 share an identical list of indicators in the source document, so grants that fall between them are ambiguous within the framework itself.
  • Only one target is accepted as the first choice, so grants that genuinely serve several targets are simplified.
